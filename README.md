# TeleICU Patient Monitoring System

## Overview
TeleICU is a computer vision–based remote patient monitoring system designed to assist healthcare professionals in observing ICU patients using video analytics.

This project was developed as part of the **Intel® Unnati Industrial Training – 2024**.

## Problem Statement
Continuous monitoring of ICU patients is resource-intensive and prone to human error. The goal of this project is to automate patient activity detection using deep learning and computer vision techniques.

## Technologies Used
- Python  
- OpenCV  
- YOLO  
- Computer Vision  
- Deep Learning  

## Methodology
- Preprocessed ICU video streams for motion detection  
- Applied deep learning models for patient activity analysis  
- Evaluated model performance using confusion matrix and precision metrics  
- Performed real-time inference on recorded and live video feeds  

## Results
The system successfully detects patient movements from ICU video feeds and provides visual outputs to assist hospital staff.

Sample results and evaluation metrics are included in the repository.
